## 2. 后端：`GET /api/regeo`（PASS）

### 2.1 契约与代码审查

- `backend/app.py::regeo_endpoint`：`GET /api/regeo?location=lng,lat`；`parse_location_text` 校验失败 → `400 INVALID_INPUT`（message「location 必须是合法的 "lng,lat" 经纬度」+ hint 示例）；**小数点后 >6 位 → 400 INVALID_INPUT（message「location 小数点后最多 6 位」，与 `/api/plan` 一致，L-v040-1 已修复）**；坐标 `round(...,6)` 后回显 `location`。
- **演示模式**：返回 `mode="demo"`、`formatted_address="当前位置（lng, lat）"`（坐标文本）、`city="北京市"`、`citycode="010"`。
- **真实模式**：调用 `AmapClient.regeo(/v3/geocode/regeo)`，返回高德 `formatted_address/city/citycode`；失败经统一异常处理返回 `AMAP_ERROR`（前端 `fetchRegeoAddress` 对非 2xx/异常降级为坐标文本）；Key 仅保存在后端、错误经 redact。
- 前端调用为同源相对路径 `api/regeo?location=...`（6 位小数），无 CORS/外部 CDN 变化。

### 2.2 HTTP 实测（演示模式，smoke 43 项）

`GET /api/regeo?location=116.397,39.908` → 200：

```json
{"mode":"demo","formatted_address":"当前位置（116.397000, 39.908000）","city":"北京市","citycode":"010","location":{"lng":116.397,"lat":39.908}}
```

- 顶层键恰为 `{mode, formatted_address, city, citycode, location}`；6 位小数坐标（`116.123456,39.123456`）正常回显。
- 非法坐标全部 4xx + 统一错误结构（`INVALID_INPUT`、message 可读、hint 字符串）：缺少 `location`、`bad`、单段 `116.3`、越界 `200,39.9`、空串、`abc,def`。
- **>6 位小数**（`116.1234567,39.9`）→ **400 `INVALID_INPUT`**，message 含「6 位」（与 `/api/plan` 一致；L-v040-1 修复后实测）。
- 响应无 Key 值形态（32 位 hex / `restapi.amap.com` / `"amap_key":` / `key=`）。

## 3. 前端：定位回显 + 保存/恢复（PASS，DOM 115 项）

### 3.1 代码审查（smoke 前端 82 项，其中定位/保存恢复 25 项）

- 定位成功后 `fetchRegeoAddress(lng,lat)` 调 `api/regeo?location=...`（10s AbortController 超时），成功用 `formatted_address` 回显；失败/非 2xx 降级为 `locateFallbackLabel()` → `当前位置（lng, lat）`；拿到地址后 `state.points[0]=detail`、按钮恢复、重绘并聚焦；等待期间保持「定位中…」且有 `state.pointLocations[index] !== located` 防覆盖保护。
- 成功后 `saveSavedLocation({lng, lat, address, updatedAt})` 写 localStorage 键 **`supernav-saved-location`**；`loadSavedLocation()` 校验经纬度范围/JSON 合法性，`restoreSavedLocation()` 在 `init()` 中恢复起点地址/定位坐标；`buildPointsPayload()` 定位点仍提交 `{location:"lng,lat"(6位), name:输入框地址}`。
- 手动编辑起点文本清除当前 `pointLocations[index]` 与 `is-located`/按钮文案（注意：不清除 localStorage，见 §6 L-v040-3）。
- 标题改为「已定位并保存：<地址或坐标>」；错误路径 code 1/2/3 提示保留。
